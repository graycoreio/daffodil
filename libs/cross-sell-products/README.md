# @daffodil/cross-sell-products
`@daffodil/cross-sell-products` is an optional package that adds the cross-sell products feature on to `@daffodil/product`.

## Installation
To install `@daffodil/cross-sell-products`, use the following commands in your terminal.

Install with npm:
```bash
npm install @daffodil/cross-sell-products --save
```

Install with yarn:

```bash
yarn add @daffodil/cross-sell-products
```
