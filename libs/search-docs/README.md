# @daffodil/search-docs
`@daffodil/search-docs` integrates `@daffodil/docs` with `@daffodil/search` to enable documentation search for daffodil generated docs.

## Installation
To install `@daffodil/search-docs`, use the following commands in your terminal.

Install with npm:
```bash
npm install @daffodil/search-docs --save
```

Install with yarn:

```bash
yarn add @daffodil/search-docs
```
